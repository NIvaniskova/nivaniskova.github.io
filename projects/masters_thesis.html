Master's Thesis

Analyzing Approximate Circuit Libraries Using Machine Learning Methods

Brno University of Technology, Faculty of Information Technology · 2026

Overview

Modern chips increasingly use "approximate" circuits – components that trade a small amount of accuracy for significant gains in speed and energy efficiency. Designing these circuits automatically, through evolutionary algorithms that explore thousands of candidate designs, requires constantly checking each candidate's real-world performance, which normally means running professional, computationally expensive circuit-design tools.

This thesis analyzes a library of approximate 8-bit multiplier circuits (EvoApproxLib) to understand the trade-offs between their accuracy, power consumption, and delay, then builds fast machine learning models that predict these hardware properties directly from a circuit's structure, without needing to run full synthesis tools each time.

Approach

Diagnostic scripts were written to examine a circuit's internal structure – how its logic gates are arranged and distributed – and turn that structure into a set of measurable features. These features were used to train machine learning models that predict key hardware properties (delay, power, chip area) and error metrics such as mean absolute error (MAE) and worst-case error (WCE), producing fast estimators that stand in for slow, resource-heavy simulation.

The work builds on evolutionary circuit design using Cartesian Genetic Programming, where thousands of candidate circuits are evaluated per run, making fast, lightweight estimation especially valuable.

Approximate Computing Cartesian Genetic Programming Evolutionary Design Surrogate Models Machine Learning

Results

The resulting indicators and models were able to stand in for the hardware attributes and error metrics that would otherwise require synthesizing each circuit with professional design tools, offering a much faster, lightweight way to estimate a candidate circuit's quality. This is especially useful during evolutionary design, where an algorithm needs to evaluate huge numbers of candidate circuits and cannot afford to run full synthesis on each one.
