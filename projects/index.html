Analysis of Approximate Circuit Libraries Using Machine Learning Methods

Machine learning models that predict hardware performance — speed, power use, and accuracy trade-offs — of approximate circuits, replacing slow, expensive simulation tools with fast, structure-based estimators. Built on Cartesian Genetic Programming and evolutionary circuit design at FIT VUT Brno.

Bachelor's Thesis

HI Chatbot — Conversational Study Assistant

A conversational solution built with IBM Watson Assistant for the "Business Informatics" study program at FEI TUKE, designed to help students adapt to university life. The chatbot provides predefined answers to selected questions about the study program and links to other useful resources. It is a prototype and cannot answer arbitrary questions independently.
